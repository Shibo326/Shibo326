> AI greenwashing detection platform. Upload sustainability reports → AI cross-references claims against data and flags contradictions in under 90 seconds.

```
Track:    Unicorn Track 🦄 — YFS Build for Good Hackathon (July 2026)
Role:     Sole Full-Stack Engineer (2–3 weeks, solo build)
Live:     https://amd-hackthon-ll14.vercel.app
API:      https://amdhackthon-production.up.railway.app
```

| Layer | Stack |
|---|---|
| Frontend | React 18 · TypeScript · Vite · TailwindCSS 4 · Framer Motion |
| Backend | FastAPI · Python 3.11 · ChromaDB · sentence-transformers |
| AI Inference | **AMD Instinct MI300X** · deepseek-v4-flash · gpt-oss-120b (646 tok/s) |
| Deployment | Railway (backend) · Vercel (frontend) |

**Key engineering:** 5 parallel LLM calls via `asyncio.gather` · RAG pipeline (600-token chunks, 80-token overlap) · tiered model routing (quality vs fast) · self-ping keep-alive system · 5-strategy JSON parsing pipeline · N→1 consolidated conflict detection · `Semaphore(3)` rate-limit protection · full PDF/DOCX export

### 🌙 NightScore — ZK Credit Scoring on Midnight

> Privacy-preserving credit scoring. Prove your creditworthiness without revealing your financial activity. Protected by NightGuard AI security.

```
Stack:    Midnight blockchain · Compact language (ZK circuits)
Demo:     https://newmoon-entry-projects.vercel.app
Tests:    669 tests (Vitest + fast-check property-based)
```

| Layer | Stack |
|---|---|
| Blockchain | Midnight · Compact ZK circuits · Prover/verifier keys |
| Credit AI | Groq (Llama 3.3 70B) |
| Security AI | Fireworks AI (Llama 3.1 8B) — NightGuard transaction screening |
| Backend | TypeScript · Node.js 22+ · 9-agent message bus architecture |
| Frontend | React 18 · Vite · Tailwind CSS · Framer Motion |
| Cache | Supabase · GitHub Actions CI/CD |

**Privacy model:** 6 private circuit inputs (wallet age, tx frequency, DeFi interactions, repayment history, asset diversity, liquidation history) never touch the ledger — only a boolean threshold result is disclosed publicly.
